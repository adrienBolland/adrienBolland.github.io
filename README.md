# adrienbolland.github.io

Personal website, built by GitHub Pages (Jekyll) and served at https://adrienbolland.github.io/.

- `index.html`: the page.
- `_data/publications.yml`: selected publications, inserted into the page automatically.
- `media/`: banner animation (wide and tall animated WebP, with still images for reduced motion), photo and tab icon (`icon.svg`, with `icon.png` for Apple devices). `media/originals/` holds the original video renders the animations are made from.
- `files/`: CV and slides linked from the page, plus one unlisted deck (`rl-sizing-operation.pdf`).

To update the CV, replace `files/cv.pdf` and change the date in `index.html`.

Local preview: run `jekyll serve` in this folder and open http://localhost:4000.
